# 实验四 S1：加权 RRF 权重对照（验证集）

- 评价口径：与课程离线评价完全一致（正反馈 ≥ 4.0、Top-10、候选排除该用户在 train 中的评分）。
- 用户集合：validation 固定评价用户 4209 位；每路候选深度 30，融合后取 Top-10。
- 选优规则：在 validation 上按 P@10（并列看 R@10）选多路配置；单路基线只作参照
- 选定配置：**ItemCF ×6 + ALS ×1**（itemcf6-als1），RRF k = 60，P@10 = 0.055785，R@10 = 0.097399。
